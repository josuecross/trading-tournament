# Global Multi-Asset ETF Fast Exploration Batch 1

This folder documents the fixed Global Multi-Asset ETF Fast Exploration Batch 1 research_sample screen.

It tests exactly three predeclared ETF/fund-wrapper candidates, does not run candidate_exhaustive, does not activate paper-forward, does not change active combo paper/demo rules, does not replace SPY_200d, does not add leverage, margin, shorting, futures contracts, options, forex, intraday logic, broker integration, live orders, order placement, or make a real-money recommendation.

All results are exploratory, non-final, not paper-forward, and not real-money evidence.
