# Strategy Candidate Queue

This queue is for candidate discovery only. It does not implement strategies, validate strategies, recommend real-money trading, connect to brokers, place live orders, or alter paper-forward rows.

The queue exists to keep research disciplined after the current Profit Exploration finalists. It separates candidates worth later implementation review from candidates that need data, execution, risk-model, benchmark, complexity, or anti-overfitting gates before any code is allowed.

The current frozen paper-forward observation remains unchanged. The current reduced Profit Exploration evidence remains separate and non-final until full 30/60/90/180 candidate-exhaustive validation is completed.

Candidates in this folder must pass the documented gates before coding. Candidate rules should stay simple, fixed, explainable, and versioned. This queue is designed to prevent random strategy shopping, parameter chasing, and evidence contamination.

No row in this queue is paper-forward active. No row is implemented by this task. No real-money recommendation is made.
