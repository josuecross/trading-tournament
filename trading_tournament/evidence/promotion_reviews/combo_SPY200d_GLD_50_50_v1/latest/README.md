# Combo SPY200d GLD 50/50 Promotion Review

This folder is a research-only promotion review packet for `combo_SPY200d_GLD_50_50_v1`.

The packet uses existing full 30/60/90/180 Profit Exploration candidate-exhaustive evidence only. It does not run a backtest, implement a strategy, change strategy rules, activate paper-forward observation, connect to brokers, place orders, or make a real-money recommendation.

The review asks whether this fixed 50/50 SPY_200d/GLD combination deserves a separate paper-forward observation plan review. It does not make the row paper-forward active.
