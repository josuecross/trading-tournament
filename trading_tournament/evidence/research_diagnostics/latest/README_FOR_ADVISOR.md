# README For Advisor

This is a diagnostics infrastructure packet only.

It adds reusable historical attribution diagnostics for future research_sample and combination-review work. It does not implement a new strategy, run candidate_exhaustive, run a backtest, download data, change paper-forward rules, connect to brokers, place orders, or make a real-money recommendation.

The optional diagnostics-only Profit Exploration command was used only to export Batch 1 attribution detail from existing cached diagnostics inputs. Normal Profit Exploration latest results were not rewritten.
