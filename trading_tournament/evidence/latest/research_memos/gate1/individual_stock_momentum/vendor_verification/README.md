# Individual Stock Momentum Gate 1A Vendor Verification

This is the Gate 1A vendor verification packet for `individual_stock_momentum`.

It is research-only. It does not approve implementation, does not validate stock momentum, does not approve a toy demo unless explicitly decided in `GATE1A_VENDOR_DECISION.md`, and does not recommend real-money trading.

The purpose is to verify whether credible stock data is realistically available for a future Gate 2 decision without unacceptable survivorship bias, delisting bias, corporate-action errors, licensing problems, or cost/runtime burden.

Recommended reading order:

1. `VENDOR_VERIFICATION_SUMMARY.md`
2. `VENDOR_COMPARISON_TABLE.csv`
3. `DATA_REQUIREMENT_CHECKLIST.csv`
4. `GATE1A_VENDOR_DECISION.md`
5. `NEXT_ACTIONS.md`

This packet does not create a stock data loader, does not implement stock momentum, does not run a backtest, and does not download historical market data.
