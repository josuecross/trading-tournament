# Issuer Metadata Review Requirements

Do not fetch issuer pages in this task.

Future metadata review must collect for each proxy:

- fund name
- issuer
- inception date
- expense ratio
- strategy/methodology summary
- whether it holds futures internally
- whether it uses managed-futures or CTA trend methodology
- whether it has internal leverage, risk target, or collateral exposure
- whether it is active or index-based
- whether wrapper-level ETF/fund price modeling is acceptable
- whether fund history is long enough
- whether methodology is too opaque
- whether evidence should be treated as fund-specific only

The project must treat these as managed-futures proxy wrappers, not direct futures strategy tests.
