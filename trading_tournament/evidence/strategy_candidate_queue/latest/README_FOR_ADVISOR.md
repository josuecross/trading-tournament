# README For Advisor

This packet is a Strategy Candidate Queue v1. It is for candidate discovery only.

It does not implement strategies, validate strategies, run backtests, recommend real-money trading, connect to brokers, place live orders, alter paper-forward rows, or alter current finalist validation.

Candidates must pass evidence, data, execution, risk-model, benchmark, diversification, complexity, target-potential, and anti-overfitting gates before any coding is allowed. The queue is designed to prevent random strategy shopping and keep future research simple, fixed-rule, explainable, and tier-labeled.
