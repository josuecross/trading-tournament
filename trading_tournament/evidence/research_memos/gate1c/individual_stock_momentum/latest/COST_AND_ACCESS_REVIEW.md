# Cost And Access Review

No prices were fetched or verified in this task.

## Cost Categories

- Free or terms-unclear: yfinance/current ticker lists, Stooq/public CSV.
- Paid or restricted: Norgate Data, Nasdaq Data Link / Sharadar, Polygon/Massive, Tiingo, EODHD.
- Institutionally restricted or likely expensive: CRSP.
- Broker/account-dependent: Alpaca, Interactive Brokers.

## API Keys And Local Cache

Most API providers likely require keys. No API key may be committed. Local cache may be allowed only if provider terms permit it. Raw vendor data must not be redistributed or placed in advisor packets.

## Can The Project Proceed Without Spending Money?

Only as Tier 1 toy/current-ticker exploration. That path is cheap and fast but cannot answer the serious stock momentum question.

## Tradeoff

Cheap/free data can test code shape but is biased. Serious survivorship-aware data likely requires paid or restricted access, more metadata, and stronger storage/runtime controls.

## Conclusion

Defer data acquisition until a provider is chosen and cost/access/terms/security are reviewed. Serious stock momentum should not proceed on free current-ticker-only data.
