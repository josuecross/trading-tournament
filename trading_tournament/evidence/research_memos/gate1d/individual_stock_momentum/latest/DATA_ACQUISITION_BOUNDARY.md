# Data Acquisition Boundary

Gate 1D does not approve data acquisition.

## A Future Gate 1E Prompt May Proceed Only After

- provider chosen,
- terms/security reviewed,
- cost/access accepted by user,
- API-key or credential handling defined,
- minimum data contract mapped to provider fields,
- local cache path and metadata plan defined,
- raw data exclusion from advisor packets confirmed,
- provider redistribution/cache restrictions accepted,
- tiny-sample scope defined before any broader cache update.

## A Future Gate 1E Prompt Must Not

- run a stock strategy,
- run a stock backtest,
- run Profit Exploration,
- run candidate_exhaustive,
- create broker integration,
- place orders,
- create live-order or order-placement behavior,
- make a real-money recommendation,
- treat current-ticker-only evidence as serious evidence,
- download a full market universe before a tiny-sample field/quality check passes.

## Current Boundary Status

The current Gate 1D review chose a provider path for future review only. No stock data was downloaded, no provider API was called, no data loader was created, and no strategy was implemented.
