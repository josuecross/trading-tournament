# Raw Data Exclusion Policy

Rules for any future Norgate sample:

- raw vendor data stays only in an approved local cache path,
- compact evidence contains only metadata, coverage, quality summaries, hashes, and field-mapping notes,
- advisor packets exclude raw vendor OHLCV,
- no redistribution of raw paid data,
- no API keys or credentials in evidence,
- no Norgate database files in zip packets,
- no screenshots of proprietary data tables if terms forbid them,
- sample row previews are forbidden unless terms explicitly allow them,
- cache manifests may include file paths and hashes only if terms allow,
- logs must not print raw vendor rows or secrets.
