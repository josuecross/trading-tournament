# Managed-Futures Proxy Provider Terms/Security Review

This is a provider terms/security review only for `managed_futures_proxy_etf_trend_v1`.

No data is downloaded. No API is called. No API key is created or stored. No strategy is implemented. No backtest is run. No futures contract logic is added. No paper-forward rule is changed. No broker integration, live orders, order placement, or real-money recommendation is made.

The review decides only whether a future controlled data download prompt may use the existing yfinance-compatible path, and under what symbol boundary.
