# Proxy Methodology Review Requirements

After data exists, the project must review each proxy's methodology before strategy implementation is considered.

Required review items:

1. Fund inception date.
2. Fund methodology summary.
3. Whether it holds futures internally.
4. Whether wrapper-level ETF/fund price modeling is acceptable.
5. Whether hidden leverage or risk target exists.
6. Whether fees and expense ratios are material.
7. Whether fund history is long enough for the project evidence tier.
8. Whether results are likely fund-specific rather than strategy-family evidence.
9. Whether the proxy has enough crisis, inflation, commodity, and rate-regime coverage.
10. Whether the candidate should be treated as managed-futures proxy evidence, not direct futures strategy evidence.

If wrapper-level modeling is not acceptable, the candidate must remain blocked because this project does not implement futures contracts, rolls, margin, or futures execution in this lane.
