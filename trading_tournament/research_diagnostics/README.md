# Research Diagnostics

Reusable historical diagnostics for research-only strategy evidence.

This folder provides attribution helpers for future Profit Exploration and Combination Lab work. The helpers operate on equity curves, return streams, and window-level diagnostics passed by callers.

Boundaries:

- no strategy implementation
- no data download
- no broker integration
- no live orders
- no order placement
- no candidate_exhaustive run
- no paper-forward rule change
- no real-money recommendation
