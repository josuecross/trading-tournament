# Commodity Risk-Control Batch 1

This folder defines a fast exploratory risk-control batch for `commodity_basket_etf_momentum_v1`.

It tests exactly three fixed, predeclared commodity-wrapper risk-control candidates in `research_sample` only. It does not run candidate_exhaustive, does not activate paper-forward, does not change the active combo observation, does not replace SPY_200d, does not use futures contracts directly, and does not make a real-money recommendation.
