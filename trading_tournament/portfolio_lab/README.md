# Portfolio Lab

This folder defines fixed portfolio-construction diagnostics for the compact challenge audit.

The diversified portfolio challenge uses predeclared mixes of already-available sleeves. It does not change paper-forward rules, approve real-money trading, add broker integration, or add blocked instruments. Each portfolio row is a separate paper/demo $3,000 challenge account.

ETF-only portfolio rows are diagnostics that may be compared in the compact challenge audit when exact all-possible windows complete. They are not automatically paper-forward ready.

Crypto-containing portfolio rows are Tier 1 exploratory only. They remain non-final, are not candidate validation, and are not real-money recommendations.

No portfolio spec here uses leverage, margin, shorting, options, futures, forex, intraday data, individual-stock loaders, or vendor APIs.
