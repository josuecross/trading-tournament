# Serious Vs Toy Path Decision

## Path A: serious_survivorship_aware_path

Requirements:

- provider with delisted names,
- delisting treatment,
- adjusted prices,
- corporate actions,
- point-in-time universe or all-listed universe construction,
- liquidity/cost model,
- higher cost and complexity,
- credible Tier 2+ potential.

This is the preferred path if a viable provider is chosen.

## Path B: tier1_toy_current_ticker_path

Requirements:

- current symbols from yfinance/free sources,
- no serious survivorship claims,
- code-path only,
- fast and cheap,
- cannot answer the main question seriously.

This is not preferred for the main objective.

## Path C: defer_until_provider_access

Requirements:

- no implementation now,
- preserve memo,
- revisit when provider is chosen.

## Recommendation

Recommend Path A in governance form only: choose a serious provider for terms/security review before any data acquisition. If cost/access blocks that path, defer. Do not approve toy implementation as the next step.
