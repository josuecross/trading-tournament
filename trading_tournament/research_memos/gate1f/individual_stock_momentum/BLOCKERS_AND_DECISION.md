# Blockers And Decision

## Blockers

- no subscription/package selected,
- API key not configured,
- terms/cache rights unknown,
- delisting treatment unknown,
- PIT/all-listed universe support unclear,
- ticker-history identifiers unknown,
- local cache rights unknown,
- raw data redistribution prohibited unless terms allow narrow local use,
- package cost unknown or unacceptable until user review,
- no controlled sample approved.

## Fallbacks

- configure Norgate access if available,
- CRSP if institutional access exists,
- defer stock momentum,
- Tier 1 toy current-ticker path only if explicitly selected later and labeled non-serious.

## Decision Interpretation

Sharadar should remain the next fallback provider path, but the project must first select a package and review terms/security/cache rights. No API call or tiny sample is approved in Gate 1F.
