# Next Gate 1 Requirements

Before any individual stock momentum code is written, complete this checklist.

- [ ] Identify data source candidates.
- [ ] Determine whether survivorship-free data is available.
- [ ] Determine whether delisted stocks are included.
- [ ] Determine whether corporate actions are handled.
- [ ] Define initial universe rules.
- [ ] Define liquidity filters.
- [ ] Define earnings avoidance or handling rule.
- [ ] Define benchmark universe.
- [ ] Define slippage/spread assumptions.
- [ ] Define risk model.
- [ ] Define validation plan.
- [ ] Define kill criteria.
- [ ] Estimate runtime and storage impact.
- [ ] Decide whether project budget/time justifies implementation.

Gate 1 output should be a feasibility document, not code. If any critical item fails, the idea remains deferred.
