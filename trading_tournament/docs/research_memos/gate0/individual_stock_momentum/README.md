# Individual Stock Momentum Gate 0 Memo

This is a Gate 0 research memo for `individual_stock_momentum`.

It is research-only. It does not approve implementation, does not validate a strategy, does not add stock data loaders, does not add trading logic, and does not recommend real-money trading.

The purpose is to decide whether individual stock momentum deserves Gate 1 feasibility review. Gate 1 would still be a research and feasibility step, not a prototype.

Recommended reading order:

1. `GATE0_MEMO.md`
2. `FEASIBILITY_SCORECARD.csv`
3. `GATE0_DECISION.md`
4. `NEXT_GATE1_REQUIREMENTS.md`
