# Crypto Spot Tier 2 Risk-Control Batch 1

This folder defines a fixed fast exploratory BTC/ETH spot-only risk-control batch.

It does not run candidate_exhaustive, activate paper-forward, change active combo paper/demo rules, replace SPY_200d, add leverage, margin, shorting, futures, perpetuals, options, broker integration, exchange execution, live orders, order placement, or make a real-money recommendation.

The batch is research_sample only and uses public/cached crypto spot data with explicit exploratory labels.
